## About

Sanskriti Mall is a premium men's fashion ecommerce experience for Badora, Betul, Madhya Pradesh. The storefront combines editorial fashion presentation with practical ecommerce flows and a browser-persistent local demo mode.

## Highlights

- Premium responsive storefront and editorial fashion UI
- Collections, product detail pages, search and filtering
- Browser-persistent shopping bag and wishlist
- Coupon flow with `STYLE10`
- Checkout and browser-local order tracking
- Customer account and saved order history demo
- Styling studio and style finder
- Store-team admin demo with products, stock, orders and settings
- Local SEO metadata and social preview artwork
- GitHub Pages automated deployment

## GitHub Pages Demo

The GitHub Pages deployment is a static demo build. Products, cart, wishlist, account preferences, checkout orders and admin demo data are stored in the current browser/device.

For a real production ecommerce launch, connect secure authentication, PostgreSQL/Supabase, media storage and a payment gateway.

## Local Development

```bash
npm install
npm run dev
npm run build
```

Node.js `22.13+` is recommended for this project.

## Project Structure

- `app/` — storefront, account, checkout, product, order and admin routes
- `components/` — ecommerce UI, visual system and interactive experiences
- `lib/catalog.ts` — initial merchandise and store settings
- `lib/types.ts` — shared commerce data model
- `public/images/` — storefront and campaign imagery
- `public/og.png` — social/README preview image
- `.github/workflows/deploy.yml` — GitHub Pages deployment
